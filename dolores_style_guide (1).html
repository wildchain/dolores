01 · Brand mark

Logotype

08 · Accessibility

Accessibility rules

Non-negotiables that must carry across any new asset or slide.

  • Focus indicator: All interactive elements show a 2px --accent outline with 3px offset on :focus-visible. Never remove this — rebrand it if needed, but keep visibility.
  • Reduced motion: All transitions and animations are disabled under @media (prefers-reduced-motion: reduce). Never rely on motion to convey meaning.
  • Color contrast: Body copy must sit on --fg (near-black) or --primary (on dark). --fg-subtle is decorative only — fails WCAG AA at small sizes for body copy.
  • Don't convey by color alone: The semantic palette (ok/warn/danger) must always pair with an icon, label, or text — never use color as the only signal.
  • Fluid type: All sizes are clamp()-based so they scale between 360px and 1920px viewports without breaking.

09 · Do & Don't

Quick rules

Hard-won opinions from the pitch deck. Carry these into any new slide or marketing surface.

Do

Reference color tokens (var(--accent)), never hex codes, in new CSS.

Use --accent for stats, kickers, links, and interactive affordances — it's the hardest-working color in the system.

Pair .kicker + h1.claim + h2.sub at the top of every section for a consistent rhythm.

Use JetBrains Mono for numbers, tags, and metadata — never for prose.

Keep ambient background gradients on every slide. They're the signature.

Don't

Don't use --fg-subtle for body text — it's decorative only and fails contrast.

Don't use --accent as a text color for sentences — it's fine for short labels but becomes painful on paragraphs.

Don't stack more than two card shadows (--shadow-md) on the same slide — it flattens the hierarchy.

Don't place --navy panels next to --surface-sunken — the contrast jumps too hard.

Don't hand-tune spacing in pixels. Use the 8-pt scale implied by the existing components (8, 10, 14, 16, 20, 24, 28, 32, 40, 48).
